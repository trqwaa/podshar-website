# Зал — подвальная качалка

Пробная версия раздела, ветка `trial/zal`. На прод не выкатывалась: таблиц
зала в настоящей базе ещё нет (см. «Миграция»). Правила, которые легко
сломать, — в `CLAUDE.md`, раздел «Зал»; здесь — как всё устроено и что дальше.

## Что есть

| адрес | что там |
|---|---|
| `/gym` | подвал: анимированная сцена, мопс делает упражнение дня, меню из трёх предметов, мопс-критик |
| `/gym/training` | качалка: доска с планом, тренировка как в Strong, история, цели и замеры, справочник упражнений (`?tab=`) |
| `/gym/food` | питание: дневник дня с КБЖУ, как FatSecret (`?day=`) |
| `/gym/sleep` | сон: две недели, ночь руками, импорт CSV |

Везде `?who=<хендл>` открывает чужой дневник на чтение. Дневник у каждого свой,
видят все трое, пишет только хозяин — проверка по сессии в каждом действии.

**Подвал** (`components/gym/GymScene.tsx`) сделан как пульт-айсберг: SVG-сцена,
небо в окошке под потолком — по закату над Цюрихом (`lib/sun.ts`, настроение
считает сервер), живое — мимо React: мопс (`PugRig`) пишет атрибуты из
`requestAnimationFrame`, лампочка, пыль и ботинки за окном — CSS. Упражнение
дня — по плану того, чей дневник открыт: толкающий день — жим 200, тянущий —
тяга 100 к поясу, ноги — присед 180 (`showcaseFor`). Дня в плане нет — мопс в
капюшоне сидит на скамье с телефоном. Плана нет совсем — упражнение по номеру
дня, одинаково у троих.

**Мопс-качок** — два рисунка:

- `PugRig` — профиль в полный рост, скелет с двузвенной обратной кинематикой.
  Поза задаётся тем, что видит тренер: где таз, наклон корпуса, где гриф, где
  стопы (`pug-motions.ts`); локти и колени решаются сами, поэтому гриф в жиме
  идёт по прямой, а стопы в приседе стоят на месте. 27 движений на 31
  упражнение. Без движения (`prefers-reduced-motion`) — стоп-кадр в середине
  повтора. Анимация спит, пока мопс за краем экрана.
- `PugFace` / `PugAvatar` — морда анфас с выражениями (`happy`, `proud`, `meh`,
  `sad`, `angry`, `sick`, `sleepy`, `overslept`, `shocked`) и аватар в майке.
  В зале он же — в углу экрана вместо мопса в капюшоне (`AssistantAvatar`).

**Мопс-критик** (`lib/gym/critic.ts`) — приговор неделе по питанию, качалке и
сну, оценки 0–10, что делать и добавки (что имеет смысл и чего не трогать).
Работает на правилах всегда; реплики — в `critic-lines.ts` на четырёх языках,
голосом мопса из `assistant/brief.ts`. Кнопка «разнести по-взрослому» зовёт
модель (`critic-model.ts`) с тем же досье, что у правил, — факты у них общие.
Ответ ложится в `gym_verdicts`: повторный заход бесплатен, и разнос видят все трое.

`/gym` отдаст 500. База одна на троих — накатывать только сговорившись:

```sh
set -a && . ./.env.local && set +a
npx prisma migrate deploy
```

## Что заглушено и что потом

- **Сон с часов.** У Zepp Life нет открытого API. Сейчас — ручной ввод и импорт
  CSV: выгрузка Zepp Life (папка `SLEEP`, колонки `date, deepSleepTime,
  shallowSleepTime, wakeTime, start, stop[, REMTime, naps]`) или любая таблица с
  началом и концом сна. Ночи, введённые руками, импорт не перетирает.
  Дальше, по порядку пользы:
  1. **Айфон**: Zepp Life → «Здоровье» → быстрая команда, которая каждое утро
     шлёт ночь на сайт. Нужен эндпоинт `/api/gym/sleep` с личным токеном
     (хранить SHA-256, как приглашения) — полдня работы, без миграции не
     обойтись (таблица токенов или поле).
  2. **Андроид**: Zepp Life → Health Connect. Читать его может только
     приложение на телефоне, сайт — нет. Маленький компаньон на Kotlin или
     Capacitor; это уже отдельный проект.
  3. Неофициальный облачный API Zepp (токен из браузерной сессии) — хрупкий,
     ломается без предупреждения; не советую.
- **Справочник еды** — 63 позиции в коде (`lib/gym/foods.ts`), значения на
  100 г из открытых таблиц. Своя еда вводится руками, фастфуд по названию
  узнаёт `junkByName`. Сканер штрихкодов и Open Food Facts — потом.
- **Нормы** — Миффлин — Сан-Жеор × активность × цель, белок 1,8–2,2 г/кг;
  сон — AASM/NSF по возрасту, «невыспался» — меньше 7 часов. Возраст — из дня
  рождения в профиле сайта, иначе год рождения из зала, иначе 17.
- **Модель критика** — та же, что у мопса-навигатора (`MODEL` в
  `assistant/model.ts`, сейчас Sonnet по решению владельца): одна ручка цены
  на оба. Зовётся только по кнопке, не чаще раза в две минуты и не больше
  двадцати в сутки на человека. Без `ANTHROPIC_API_KEY` кнопка честно говорит,
  что модели нет, а разнос на правилах остаётся. Один разнос — около $0.006
  (лог: `[podshar] critic …`). Промпт короче порога кеша, поэтому `cached` у
  него ноль — это не утечка.
- **Не сделано**: строка зала в ленте новостей (`lib/news.ts`, источник), мопс
  не умеет сам записывать еду и подходы, нет перетаскивания упражнений на
  доске и графиков веса в упражнениях, нет запись в `patches.ts` (при выкатке —
  новый раздел, `+0.10`).

## Проверить локально

Без настоящей базы: свой Postgres (embedded-postgres, как в `RESUME.md`),
миграции на него и демо-данные.

```sh
DATABASE_URL=postgresql://postgres@localhost:5433/podshar_local \
DATABASE_URL_UNPOOLED=postgresql://postgres@localhost:5433/podshar_local \
npx prisma migrate deploy

DATABASE_URL=postgresql://postgres@localhost:5433/podshar_local \
node prisma/seed-gym-local.mjs ../gym-logins.md

DATABASE_URL=postgresql://postgres@localhost:5433/podshar_local \
DATABASE_URL_UNPOOLED=postgresql://postgres@localhost:5433/podshar_local \
npm run dev
```

Сид отказывается работать, если `DATABASE_URL` смотрит не на localhost. Он
заводит троих тестовых — «качок» (всё по плану), «соня» (план есть, сна нет),
«фастфуд» (ни плана, ни совести) — и пишет их общий пароль в указанный файл.
Файл — вне репозитория: пароль тестовый, но репозиторий публичный.
