# Как продолжить работу над Podshar

Этот файл — для новой сессии Claude Code (или другого агента), которая ничего не
знает о предыдущих разговорах. Он не про код: код объясняет сам себя. Он про то,
как за пять минут понять, где мы остановились, и не сломать то, что уже решено.

---

## 1. Что прочитать, в этом порядке

| | зачем |
|---|---|
| `CLAUDE.md` | правила проекта и тон. Грузится автоматически, читать не надо |
| `git log --oneline -15` | что происходило последним. Сообщения коммитов подробные, в них есть «почему» |
| `docs/WHY.md` | **только** когда собираешься тронуть конкретное правило: там его разбор, замеры и отвергнутые варианты |
| `docs/ARCHITECTURE.md` | замысел целиком и дорожная карта по фазам |
| `docs/HISTORY.md` | архив всех промптов 0.1+. Открывать **только** ради конкретного старого эпизода — файл большой |

**Не читай `WHY.md` целиком на старте.** Он для того и отделён: `CLAUDE.md`
платится каждой сессией, `WHY.md` — только когда понадобился. 15 сентября 2026
из `CLAUDE.md` вынули все длинные разборы, и он похудел с 44,7 до 17,8 КБ; если
однажды снова разбухнет — значит в него дописывают истории вместо правил.

Правило простое: **в `CLAUDE.md` идёт то, что остановит от поломки, в `WHY.md` —
то, что объяснит.** Подробности отдельного захода — в сообщение коммита.

## 2. Проверить, что окружение на месте

```sh
node -v                  # нужен 20+
git status --short       # пусто = всё закоммичено
git log --oneline -1     # где мы
```

Если папка свежая (склонирована с GitHub), в ней **не будет** `.env.local`,
`.neon` и `.vercel` — они в `.gitignore`, потому что содержат секреты. Без
`.env.local` локальный сайт не подключится к базе. Восстановить:

```sh
npm install
neon link --project-id small-unit-17442214 --branch production -y
npx prisma generate
```

`neon link` сам запишет `DATABASE_URL` и `DATABASE_URL_UNPOOLED` в `.env.local`.

Браузера для проверки (пункт 5) на машине может не быть: Chrome и Edge здесь не
установлены, а Safari не умеет CDP. Ставится отдельно и мимо `package.json`:

```sh
npx @puppeteer/browsers install chrome-headless-shell@stable
```

Без базы `npm run dev` всё равно работает — в разработке сайт открыт как Guest,
и приветствие, мопс и главная проверяются полностью.

## 3. Посмотреть, что в базе

Быстрее всего — скриптом, а не на глаз. Переменные лежат в `.env.local`,
Prisma CLI их сам не читает, поэтому в bash:

```sh
set -a && . ./.env.local && set +a
npx prisma studio          # или свой скрипт через @prisma/client
```

Что обычно нужно знать: сколько пользователей, какие инвайты свободны и когда
истекают. Инвайты — это весь список допущенных: строка в `invites` = человек,
который может зарегистрироваться.

## 4. Запуск и деплой

```sh
npm run dev        # локально, http://localhost:3000
npm run build      # проверка сборки
npm run deploy     # выкатить на podshar-website.vercel.app
```

**Автодеплой работает** — пуш в `main` сам выкатывает прод. Так стало после
переноса репозитория на trqwaa; почему это было не сразу — в `CLAUDE.md`,
раздел «Инфраструктура». `npm run deploy` остался для выкатки без коммита.

## 5. Как здесь принято проверять работу

Не «должно работать», а посмотреть своими глазами:

1. `npx tsc --noEmit`
2. `npm run build`
3. headless-браузер через CDP: консоль без ошибок, hydration без расхождений,
   все четыре локали (`/ru /en /uk /de`) и мобильная ширина 390px

Пункт 3 ловил почти все настоящие баги в этом проекте — от невидимого
перетаскивания до открытого для всех сайта. Пропускать его дорого.

**Мопса можно проверять без ключа и без денег.** SDK читает `ANTHROPIC_BASE_URL`,
поэтому вместо API поднимается свой HTTP-сервер: он сохраняет то, что мы
отправили, и отвечает заготовленным ответом.

```sh
ANTHROPIC_API_KEY=sk-ant-mock ANTHROPIC_BASE_URL=http://localhost:4010 npm run dev
```

Так проверяются вещи, которые иначе всплывут только на настоящем ключе: сам
системный промпт (его видно целиком), beta-заголовок, ветка с инструментом
навигации, добор реплики вторым запросом и уход в словарь при отказе. Неверный
ключ для этого не годится — 401 приходит до того, как API посмотрит на тело
запроса, так что ошибку в запросе он не покажет.

## 6. Чего не делать

- Не коммитить `.env.local` и вообще ничего с секретами. В репозитории из
  env-файлов только `.env.example`.
- Не открывать сайт наружу «на время»: правило fail-closed в
  `src/lib/auth/config.ts` появилось после того, как приватный сайт из-за одной
  незаданной переменной сутки был доступен всему интернету.
- Не менять решения из раздела «Решения, которые легко случайно отменить» в
  `CLAUDE.md`, не прочитав, почему они такие.
- Не тратить настоящие инвайт-токены на тесты. Для проверки регистрации
  создаётся временный инвайт, потом удаляется вместе с тестовым пользователем.

## 7. С чего начать разговор

Скажи вслух, своими словами: на чём проект стоит сейчас и что предлагаешь
делать. Дождись подтверждения, прежде чем менять код. Владелец проекта не
программист — объясняй причины, а не только действия.
