- **Домен `podshar.ch`** (куплен на Hostpoint). Порядок:
  1. в Vercel добавить домен в проект (и `www`);

## Грабли (macOS), в дополнение к вашим

- **Стенд с базой:** `npm i -D embedded-postgres` на время, после — `npm
  uninstall`, **`package.json` не коммитить**. `prisma migrate deploy` требует
  обе переменные, `DATABASE_URL` и `DATABASE_URL_UNPOOLED`, иначе падает на
  валидации ещё до подключения.
- **Сид сырым `pg` врёт на два часа:** колонки `timestamp without time zone`, и
  драйвер кладёт туда настенное время машины, а Prisma читает их как UTC. В
  сиде передавайте UTC строкой: `d.toISOString().replace('T',' ').replace('Z','')`.
- **Никогда `npm run build` при запущенном `next dev`** — затрёт `.next` стенда.
  Сборку проверяйте в отдельном клоне.
- **`chrome-headless-shell@latest` ставится в папку проекта** — после проверки
  удалить папку и **убить процессы браузера**: один забытый прожил пять часов и
  долбил `/api/presence` протухшей сессией.
- **CDP-скрипты — с таймаутом на каждый вызов:** без него один невернувшийся
  ответ подвешивает весь прогон.
- **Серверные действия атаковать так:** записать настоящий запрос из браузера
  (`Network.requestWillBeSent` с заголовком `next-action`) и повторять его пачкой
  напрямую — так ловились гонки во входе и в сбросе.
- **Логи Vercel у NellleT не открываются:** его аккаунт не в скоупе `trqwaa`.
  Упавший деплой он видит только через `gh api …/commits/<sha>/status`. После
  пуша досматривайте деплой до зелёного.
- **Prettier в проекте без конфига**, а стиль — одинарные кавычки, без
  завершающих запятых, ширина 100. Запускать с `--single-quote --trailing-comma
  none --print-width 100`, иначе перепишет файл в чужом стиле.
- Локальные ветки `trial/*` влиты в `main`; `experiment/*` на origin устарели.
