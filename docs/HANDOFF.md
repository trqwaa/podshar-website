## Что знать, прежде чем трогать игры

Всё это есть в `CLAUDE.md` одной строкой и в `WHY.md` подробно. Здесь коротко:

- **Наружу ходим только из браузера**, через `/api/games`. Всё, что вызывается в
  `(app)/layout.tsx`, ждёт каждая страница сайта.
- **Значения лежат снимками**, наружу раз в полчаса. OpenDota отвечает то за
  271 мс, то за 11 секунд — замерено.
- **`/api/games` это POST, не GET.** GET браузер запомнил и показывал «привяжи
  аккаунт» тому, кто уже привязал. Плюс запрос пишет снимок.
- **Brawl только через `bsproxy.royaleapi.dev`**: ключ Supercell привязан к IP
  `45.79.218.79`, у Vercel своего адреса нет. Напрямую 403.
- **Numeric MMR в доте не существует.** Есть медаль и место у Immortal.
- **Винрейт в бравле — по журналу боёв**, не за всё время: Supercell отдаёт
  победы, но не поражения.
- **Выбор аккаунта из списка наружу не ходит.** Ходил — не успевал — записывал
  пустое имя, и ник пропадал от нажатия на него.

## Грабли (Windows), в дополнение к вашим

- **Edge для CDP надо запускать с `--headless=new`.** Без флага он стартует, но
  `/json/version` не отвечает, и скрипт падает на «no devtools».
- Порт занят — `Get-NetTCPConnection -LocalPort N -State Listen`, а не
  `netstat | grep LISTENING`: на немецкой Windows он печатает `ABHÖREN`.
- Гостевой режим при живом `.env.local`: `DATABASE_URL= npx next dev -p 3100`.
  Пустая строка переживает загрузку env-файлов.
- Скрипт с `@prisma/client` должен лежать **внутри проекта**, иначе Node его не
  найдёт.
- Python-скрипт, печатающий кириллицу, падает на выводе: ставить
  `PYTHONIOENCODING=utf-8`.
