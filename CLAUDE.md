# Podshar

Приватный сайт для троих друзей. Не продукт, не портфолио — внутренний хаб,
который должен быть приятным, слегка ироничным и явно самодельным.

Этот файл читается **целиком в начале каждой сессии**, поэтому здесь только
правила: что нельзя случайно отменить и чем это кончится. Разборы, замеры и
отвергнутые варианты — в `docs/WHY.md`, заголовки там совпадают с
формулировками отсюда. Туда идут, когда собираются что-то из этого тронуть.

| куда смотреть | когда |
|---|---|
| `docs/WHY.md` | собираешься тронуть правило и хочешь знать, во что оно упиралось |
| `docs/RESUME.md` | начал сессию: как проверить, где мы стоим, и чего не делать |
| `docs/HANDOFF.md` | после `git pull`, если пришло много с другой стороны |
| `docs/ASSISTANT.md` | правишь мопса |
| `docs/ARCHITECTURE.md` | замысел целиком и дорожная карта |
| `docs/HISTORY.md` | нужен конкретный старый эпизод. Большой, сам не грузится |
| `git log` | то же короче. Сообщения подробные, в них есть «почему» |

## Тон

Строчные буквы в лейблах, разговорные подписи, самоирония: «ну привет», «кто это
вообще», «не нажимать». Сайт делают трое своих, а не отдел маркетинга.

Четыре каталога — английский, русский, украинский, немецкий — правятся **вместе**.
Отсутствующий ключ роняет рендер, а не деградирует.

У мопса тон жёстче: хамит, иронизирует, матерится вполсилы — примерно в одном
ответе из семи. Он единственный персонаж, всё остальное говорит ровным голосом.
Граница важнее градуса: подколки адресованы тому, кто в чате, и тому, что он
делает, но никогда не бьют по живому.

Семь эмодзи, закрытый набор, всегда в конце строки. Доза и список — `docs/WHY.md`
и `assistant/brief.ts`.

Исключение: `aria-label` и тексты для скринридера остаются осмысленными. Шутки —
в видимом тексте, не в доступности.

## Стек

framer-motion 13 · Manrope

## Правила, которые легко случайно отменить

### Вход и доступ

**Не next-auth.** Его Credentials-провайдер умеет только JWT — сессии стали бы
неотзываемыми, а таблица `Session` мёртвой.

**Fail closed** (`lib/auth/config.ts`). В проде без базы сайт **закрыт**, в
разработке без базы открыт. Обратное однажды на сутки отдало приватный сайт всему
интернету из-за одной незаданной переменной.

**Middleware — не защита.** Он в Edge Runtime, Prisma там не грузится: проверяет
только наличие куки. Настоящая проверка — в `(app)/layout.tsx`. Поэтому же у
`lib/auth/cookie.ts` нет импортов.

**Пароль сверяется даже когда пользователя нет** — против `DUMMY_HASH`. Иначе по
времени ответа перебираются существующие хендлы.

**Инвайт гасится в одной транзакции с созданием пользователя**, `claimedAt: null`
стоит в фильтре `updateMany` — это же защита от гонки.

**Смена пароля убивает остальные сессии**, свою текущую сохраняет.

**Приглашение показывается один раз**, в базе только SHA-256. Выпускает только
OWNER, роль проверяется на сервере.

**`directUrl` в схеме.** Приложение через пулер, миграции напрямую: PgBouncer в
transaction mode не даёт сессию, которая нужна `prisma migrate`.

### Главная и оформление

**Приветствие и цитата — по общему номеру дня** (`lib/day.ts`), не
`Math.random()`. Случайное число дало бы расхождение гидратации на каждой
загрузке и новую шутку на каждый F5.

**Аватар — `avatarPreset`, а не файл.** Загрузка тянет за собой весь
медиа-пайплайн ради картинки в 44 пикселя.

**Лианы у кнопки — SVG, не градиенты**, считаются в `useAnimationFrame` и пишутся
прямо в DOM, без React-state.

**Анимации уважают `prefers-reduced-motion`** и не ре-рендерят React покадрово.
Значения живут в motion values.

**Поля ввода 16px на телефоне** (`text-[1rem] sm:text-[0.9375rem]`). Меньше —
айфон зумит страницу при тапе и оставляет зумнутой. Новое поле — так же.

**Прокрутку под окнами запирать на `html`, не на `body`.** На body он становится
контейнером прокрутки, и липкая шапка перестаёт липнуть. Так сломалось в 0.31.

**Ничего не отбрасывает тень.** Глубина — заливками и волосяными линиями.

**Цвет только токеном**, никогда числом. Новый цвет — новый токен в
`globals.css` с объяснением, зачем он.

### Патчи

**Выкатил заметное — допиши строку в `src/lib/patches.ts`.** Часть ритуала
коммита наравне с сообщением.

**Одна обнова — одна запись**, сколько бы правок в неё ни вошло. Решение
владельца от 14 сентября 2026. Формулировка — то, что человек заметит, открыв
сайт, а не перечень правок.

**Номер руками**, сортировка числом. Записи **не переводятся**; подписи блока —
переводятся.

**Панель патчей — диалог в состоянии, не перехватывающий маршрут Next.** Попытка
кончилась `TypeError: initialTree is not iterable` на каждом переходе. Не пробуй
заново без свежей версии Next.

**Подпись — ник из базы, в файле хендл.** Хендл переживает переименование.

### Мопс

**Голос измерен по их же переписке**, а не придуман: 7239 сообщений, мат 15%,
медиана три слова. Цифры и словарь взяты, цитаты — нет.

**Словарь и шутки в `brief.ts`, а не в каталогах**: каталоги целиком уезжают в
браузер, а это калибровка для модели.

**Внутренние шутки — не больше одной на ответ**, и в большинстве ответов ни
одной. Их всего четыре, спалить запас можно за неделю.

**Модель на модели, словарь под ней.** Не смогла — отвечает
`assistant/fallback.ts`, и снаружи не видно, какая половина ответила. Любой сбой
логируется (`[podshar] model call failed`): молчаливое поглупение иначе не
отличить от плохой модели.

**`fallbacks` берёт только Opus**, Sonnet отвечает на такой запрос 400. Флаг
едет в таблице рядом с ценой.

**Промпт один и по-английски, голос — из четырёх JSON.** Примеры подставляются на
языке зрителя: русская калибровка в немецком промпте дала немецкие фразы,
кончающиеся на «blin».

**Навигация — инструмент с enum из живых маршрутов**, не URL в тексте. Проверяет
API (`strict`), а не доверие к тому, что модель прочитала промпт.

**Thinking включён, `effort: low`.** Выключенный уводит вызов инструмента в
видимый текст: мопс говорит «веду» и никуда не ведёт.

**`/api/assistant` закрыт сессией.** За моделью открытый эндпоинт стоил бы наших
денег кому угодно.

**Ответы идут потоком, темп задаёт браузер.** Куски от модели приходят рывками;
всё принятое кладётся в очередь и выдаётся ровно. Словарь печатается с той же
скоростью — иначе по таймингу видно, какая половина ответила.

**Цену не обсуждать на глаз — она в логе.** Следить за `cached`: ноль означает,
что в промпт попало что-то меняющееся от запроса к запросу.

**`src/lib/navigation.ts` — единственный источник правды о том, что существует.**
Новый раздел добавляется сюда плюс четыре каталога, и больше никуда. У `live`-мест
обязаны быть `guide.<id>.here` и `guide.<id>.<элемент>` на всех языках.

**Термины в `navigation.ts` — подстроки.** `rain` сидит в `train`, `rang` в
`orange`, `tag` в `vintage`. Проверяй новое слово на вхождение в чужие.

### Плитки, которые ходят наружу

**Рендер не ходит в чужой API.** Всё, что вызывается в `(app)/layout.tsx`, ждёт
каждая страница сайта. Погода — через `<Suspense>`, игры — из браузера через
`/api/games`.

**Игровые цифры лежат снимками в базе**, наружу выходим раз в полчаса. OpenDota
отвечает то за 271 мс, то за 11 секунд — ходить туда на каждый показ значит
плитку, которая ведёт себя по-разному каждый раз.

**Форма привязки не теряет работу.** Сервис не ответил — аккаунт всё равно
привязан, цифры доберёт плитка. Выбор уже привязанного аккаунта наружу не ходит
вообще.

**Numeric MMR в доте не существует** — Valve не отдаёт его никому. Есть медаль,
звёзды и место в таблице у Immortal.

**Brawl Stars только через `bsproxy.royaleapi.dev`.** Ключ Supercell привязан к
IP (`45.79.218.79`), а у Vercel постоянного адреса нет. Напрямую — 403.

**Винрейт в бравле — по журналу последних боёв, не за всё время.** Supercell
отдаёт победы, но не поражения.

**Значки игр лежат в `public/`, не тянутся с чужих CDN.** Путь там однажды
сменят, и значок пропадёт молча.

**«Кто тут трётся» и поезда сделаны без миграций** — на полях, которые схема
несла с первого дня (`lastSeenAt`, `homeLocationId`).

**Календарь считается в цюрихском времени**, а не в поясе зрителя: событие в
23:30 у человека в Киеве уехало бы на следующий день, и двое спорили бы о дате.

**В календаре править и удалять может любой** — он общий на троих, автор виден в
строке. Запрет означал бы, что уехавший оставляет запись, которую некому убрать.

**Масштаб и день календаря живут в адресной строке.** Выбор дня внутри уже
загруженного отрезка идёт `history.replaceState`, без похода на сервер; смена
масштаба или периода — обычной навигацией, там нужны другие события.

**Линия «сейчас» есть только в дне и неделе.** В месяце и годе у часа нет своего
места, и класть её там некуда.

**Сетку месяца считает `calendar/scales.ts`, и только он.** Годовой вид сначала
резал плоский список по 42 дня — месяц бывает и на 35, половина года разъезжалась.

**Закладки в шторке — `BOOKMARKS` в `navigation.ts`**, и это ссылки, а не данные:
шторка в layout, любой её запрос ждёт каждая страница сайта.

**Ссылка на телеграм — переменная `TELEGRAM_INVITE_URL`, не код.** Репозиторий
публичный. Без переменной иконка просто не рисуется.

## Инфраструктура

| | |
|---|---|
| Репозиторий | github.com/trqwaa/podshar-website — **публичный**: ни секретов, ни приглашений в коде |
| Хостинг | vercel.com/trqwaa/podshar-website → **podshar-website.vercel.app** |
| База | Neon `small-unit-17442214` / production, eu-central-1 |
| Секреты | `.env.local` (в gitignore), на Vercel — переменные проекта |

**Автодеплой работает**: пуш в `main` сам выкатывает прод. `npm run deploy`
остался на случай выкатки без коммита.

Ключи на Vercel во всех трёх средах: `ANTHROPIC_API_KEY`, `RESEND_API_KEY`,
`EMAIL_FROM`, `TELEGRAM_INVITE_URL`, `BRAWL_STARS_API_TOKEN`. Отмечать
**Production и Preview** обе: галочка на одной не покрывает вторую.

Восстановление пароля по почте работает, домен `podshar.ch` подтверждён в Resend.

## Как проверять

Не «должно работать», а посмотреть:

1. `npx tsc --noEmit`
2. `npm run lint`
3. `npm run build`
4. headless Edge через CDP — консоль без ошибок, все четыре локали, 390px

Четвёртый пункт ловил почти все настоящие баги этого проекта. Первые три его не
заменяют. Скрипты лежат в scratchpad сессии.

Секреты не коммитить. В репозитории из env-файлов только `.env.example`.

## Кто что делает

Втроём параллельно: владелец (trqwaa) с этим агентом, NellleT со своим, Borys
пользуется. Перед работой — `git pull`.

**База одна на всех**: `prisma migrate` и `db push` меняют таблицы сразу у троих.
Читать сколько угодно, писать схему — только сговорившись.

Хендлов в этом файле нет намеренно: они меняются из профиля, и список успел
соврать дважды. Нужен хендл — спроси базу.

## Что дальше

1. **Настройки**: сгруппировать блоки профиля и поставить строку быстрых
   переходов. Выбор владельца — одна страница, подстраницы потом.
2. **Первый живой раздел** — мопсу некуда водить, кроме главной, профиля и
   патчей. Пять слотов «в разработке» в шторке ждут решения троих.
3. **Общий счётчик ПХ** — нужна своя таблица, то есть миграция на общей базе.
4. **Загрузка аватаров** — тянет весь медиа-пайплайн, потому и отложено.
5. **Мелкая утечка**: клиенту уезжает весь словарь переводов, включая страницы,
   куда гостя не пускают. Чинится передачей нужных неймспейсов в
   `NextIntlClientProvider`.
